📸 PixelVault – Professional Image Gallery

PixelVault is a modern, responsive image gallery web application designed to provide a clean and interactive way to explore images across different categories.

The project focuses on creating an attractive user interface with smooth interactions, image filtering, search functionality, favorites, and a full-screen lightbox experience.

✨ Features

- 🔍 Image search functionality
- 🗂️ Category-based image filtering
- 🖼️ Responsive image gallery
- 🔎 Full-screen lightbox preview
- ⬅️➡️ Previous & Next image navigation
- ❤️ Favorite images
- 💾 Favorites saved using Local Storage
- ⬇️ Image download functionality
- 🌙 Dark / Light theme
- ☰ Responsive mobile navigation
- ⌨️ Keyboard navigation
- 🎨 Smooth animations and hover effects
- 📱 Fully responsive design
- ⚠️ Image error handling

🗂️ Image Categories

- 🌿 Nature
- ✈️ Travel
- 👥 People
- 🏛️ Architecture
- 🍔 Food

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- Local Storage API
- Unsplash Images

🚀 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Explore the PixelVault image gallery.
